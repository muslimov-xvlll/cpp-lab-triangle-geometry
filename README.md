# Triangle Geometry — C++ Laboratory Work

## 📌 Description
This laboratory work implements a `Triangle` class capable of validating input points, computing side lengths, perimeter, and area, and moving the triangle in the plane.  
The program also includes functions to compare triangles by side lengths and by area.

The project demonstrates understanding of geometry, floating‑point calculations, error handling, and class design.

---

## 🛠 Implemented Features
- Validation of triangle existence (collinearity and duplicate points)  
- Calculation of:
  - side lengths  
  - perimeter  
  - area using Heron's formula  
- Sorting sides for comparison  
- Moving triangle by offset  
- Comparing triangles by:
  - equality of sides  
  - equality of areas  
- Formatted output for laboratory testing  

---

## 🎯 Educational Goals
- Practice geometric algorithms  
- Work with floating‑point precision  
- Implement class methods and private helpers  
- Use `std::array`, `std::accumulate`, `std::sort`  
- Handle invalid input via exceptions
